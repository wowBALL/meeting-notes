# กฎเฉพาะประชุม dev ล้วน

ในห้องมีแต่ทีม dev ใช้ศัพท์เทคนิคได้ตรงๆ ไม่ต้องขยายความให้คนนอกทีม

เพิ่มหัวข้อนี้เข้าไปในสรุป วางไว้ก่อน `## ต้องคุยต่อครั้งหน้า`:

```
## ติดขัดตรงไหน
- <เรื่องทางเทคนิคที่ทำให้งานไม่เดิน: รออะไร ติดที่อะไร ใครถูกบล็อก>
```

เอาเฉพาะที่ทำให้งานเดินต่อไม่ได้จริง ไม่ใช่ทุกเรื่องที่ยาก ไม่มีก็คงหัวข้อไว้แล้วเว้นว่าง
